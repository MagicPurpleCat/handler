# Хендлер — Discord-бот клана Handler / War Dogs (disnake)

Бот поднимает сервер с нуля, ведёт заявки в клан (Components v2 + стата с wardogs.tools) и карточки профиля.

## Быстрый старт

1. Создай приложение на [Discord Developer Portal](https://discord.com/developers/applications).
2. Bot → включи privileged intent: **Server Members Intent** (обязательно).
3. OAuth2 → URL Generator: scopes `bot` + `applications.commands`, права **Administrator**.
4. Создай пустой Discord-сервер и пригласи бота.
5. Установи зависимости и запусти:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# впиши DISCORD_TOKEN и опционально GUILD_ID
python main.py
```

6. На сервере: `/сервер создать`, затем `/заявка`.

## Команды

| Команда | Описание |
|---------|----------|
| `/сервер создать` | Категории, каналы, роли, эмбеды |
| `/заявка` | Панель Components v2: лого + текст + кнопка «Подать заявку» |
| `/заявка_список` | Очередь для офицеров |
| `/профиль` | Картинка-догтаг |
| `/привязка установить` | Привязать профиль wardogs.tools по ссылке |
| `/привязка обновить` | Обновить стату с уже привязанного профиля |
| `/привязка статус` | Показать текущую привязку |
| `/класс` | Основной класс в профиле |

Статистика всех привязанных профилей **автообновляется каждые 10 минут**.

После `/сервер создать`: роли классов Assault…Pilot; контент в `#тактика` и `#лут-и-фов`; в `#роли` — селект «за кого играешь».
При одобрении заявки выдаются класс-роли по форме + топ-стату с wardogs.tools.

## Чеклист готовности

- [ ] `/сервер создать` создал ИНФО / НАБОР / КЛАН / ГОЛОС / ШТАБ и роль `War Dog`
- [ ] `/заявка` показывает лого, текст и кнопку (Components v2)
- [ ] Кнопка «Подать заявку» открывает модалку
- [ ] Заявка со ссылкой wardogs.tools уходит в `#мод-заявки`

## Роль бота в Discord

Поставь роль бота **выше** ролей `War Dog` / `Командир`, иначе выдача ролей упадёт с Forbidden.

## Amvera

1. На [cloud.amvera.ru](https://cloud.amvera.ru) создай приложение (Python).
2. В переменных окружения: `DISCORD_TOKEN`, по желанию `GUILD_ID`. Файл `.env` в git не клади.
3. В Discord Developer Portal у бота включи **Server Members Intent**.
4. Привяжи репозиторий и запушь (ветку `master` или `main` — как покажет кабинет):

```bash
git remote add amvera https://git.amvera.ru/<логин>/<имя-проекта>
git push -u amvera master
```

5. Смотри логи сборки и запуска в кабинете.

База (`handler.db`) на Amvera лежит в `/data` — это постоянный том. Папка `data/` в репозитории — не то же самое, при пересборке она откатится. Секреты только в переменных Amvera.
